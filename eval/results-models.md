# Model comparison

Live run, 2026-10-29 10:17 UTC. Generated by `LIVE_TESTS=1 uv run python -m router.compare`. This file is separate from `eval/results.md`, which is Stage 1 only.

## Method

- Stage 1 runs once per case from the benchmark facts. Every system gets the same policy verdict, evidence, and `EV-n` ids.
- Every system goes through the production `route()`: same prompts, same JSON schema, Nano call with `enable_thinking=False`, one retry, then the same citation, lattice, and fail-closed checks.
- A rival fills the Nano, Super, and Ultra slots. Ids are accepted only if `GET /v1/models` lists them.
- Temperature: 0.0 for every system.
- Systems run in rotated order per case. A spend stop drops whole cases, never one system's share of a case.
- ALLOW cases do not reach a model. They are run once as a control.
- REVIEW cases at risk ≥ 0.6 (Ultra slot): 0. Ultra-slot calls made: 0.
- Cost is reported only for Nemotron tiers on the receipt table (`2026-10-25 token-factory-catalog`). Rivals show tokens only.
- Run cap: $5.00 (`DAILY_SPEND_CAP_USD`). Counted spend: $0.0682. Unpriced rivals are counted at Ultra rates for the cap only. The cap was not reached.

- *Failed closed*: a Token Factory error or a schema failure after one retry. The verdict stays at least REVIEW. An answer of BLOCK fails the schema (`llm_verdict` is ALLOW or REVIEW only), so it is counted here.
- *Dropped: bad id field*: `route()` dropped the sentence because its `evidence_ids` field was empty or named an id not in this check.
- *Dropped: no id in text*: `validator/citations.py` dropped the sentence because the sentence text itself does not contain a valid `EV-n`.
- *llm below ceiling*: the model answered ALLOW where the policy is REVIEW or BLOCK. REVIEW on a BLOCK case is the schema ceiling and is not counted. The lattice ignores a lower answer.
- *Final ≠ policy*: must be 0 for BLOCK and REVIEW cases. Any other value is a bug.
- Latency is model time per case (sum of calls), not end-to-end.
